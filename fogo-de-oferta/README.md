# Landing Page - Fogo de Oferta

Landing pages estáticas em HTML, CSS e JavaScript para apresentar o projeto Fogo de Oferta a dois públicos diferentes.

## Como usar

1. Extraia o ZIP.
2. Abra `index.html` para a apresentação destinada ao consumidor.
3. Abra `lojistas.html` para a apresentação destinada a mercados e comércios.
3. Para publicar, envie a pasta inteira para Netlify, Vercel, GitHub Pages ou outro servidor estático.

## O que foi incluído

- `index.html`: proposta, recursos e validação do aplicativo para o consumidor.
- `lojistas.html`: proposta comercial independente, com benefícios, painel e parceria.
- Identidades visuais próprias para cada público: quente e cotidiana para consumidor; azul e profissional para lojistas.
- Logo, animação e telas reais do app.
- Componentes visuais inspirados no estilo UIverse.
- Animações com GSAP + ScrollTrigger.
- Animações de bloco com Motion via CDN.

## Pontos para personalizar

No arquivo `index.html`, substitua:

- `https://forms.gle/INSERIR-LINK-CONSUMIDOR`

pelo link real do formulário de consumidores. O formulário de lojistas já está conectado em `lojistas.html`.
